# 每日微信新闻

纽约时间每天上午 9 点，由当前 Codex 定时任务浏览新闻并生成中文概要；GitHub 收到日报后发布公开网页，再通过用户自己的微信测试号发送一条通知。此方案不调用付费 AI API，不把 ChatGPT 登录凭证放进 GitHub；摘要生成使用当前 Codex 订阅额度。

**配置状态：GitHub Pages 发布及微信接口测试已通过，用户已确认收到通知；纽约时间每天上午9点的定时任务已启用。2026-09-16已发送测试日报，下一份新日报为2026-09-17。**

仓库：https://github.com/Nek0doz/wechat-news-daily

## 筛选标准

- 先收集多个来源，再核对原文、发布时间和事件进展；抓取顺序不等于最终排名。
- 信源不限于中文媒体或中文社区。每次主动检索英文及其他相关语言的原始报道、官方发布和当地可靠媒体，尤其世界新闻、美国及当地新闻与CS2须覆盖非中文信源；按可靠性、重要性和时效筛选，不为凑语言比例收录低质量内容。
- 外语新闻核实后，用自然准确的中文写1至2句简要译述，保留原文的不确定性、信息归属、关键数字和专有名词。来源名称保持可识别，链接指向原始语言的原文，不替换成中文转载、翻译站或聚合页。社区帖子可作线索，未经核实的传闻不当作新闻事实。
- 世界与中国新闻优先重大公共事件、政策、经济、科技及灾害等；深圳优先民生、交通、公共服务与城市动态；CS2优先官方更新、重要赛事和主要战队变动。
- 排除营销软文、无新进展的旧闻、未经证实的传闻以及同一事件的重复报道。
- 每板块最多3条，不凑数；重要争议应区分已确认事实、当事方说法与尚待确认信息。
- 以1至2句概括发生了什么，必要时说明有来源支持的影响；不把猜测写成事实。多个独立可靠媒体有助于交叉核对，不能长期只依靠单一媒体的榜单。

- 美国新闻优先全国性政策、经济和重大公共事件；宾夕法尼亚州新闻优先州政策、公共服务及全州影响事件；State College 新闻以宾夕法尼亚州 State College 及周边 Centre County 为范围，优先当地民生、交通、公共安全、市政和与当地居民相关的 Penn State 动态。相同事件只放在最相关板块：地方事件优先地方板块，州级事件优先州板块，全国事件优先美国板块；世界新闻侧重其他国家和跨国事件，避免重复。

## 内容

世界新闻、美国新闻、宾夕法尼亚州新闻、State College 新闻、中国新闻、深圳新闻、CS2 游戏资讯，每板块最多 3 条，每条为简洁概要和原文链接。只采用生成前 24 小时内的来源；缺少可靠更新时注明，不以旧闻凑数。概要由定时任务核实后写入，不由这个仓库自行生成。

## 配置

1. 创建自己的 GitHub 仓库，把本目录文件上传到 `main`。
2. Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
3. 在微信测试号后台添加模板，标题为“每日新闻简报”，模板内容见下方。
4. Settings → Secrets and variables → Actions 添加以下 Repository secrets：
   - `WECHAT_APP_ID`：测试号 appID。
   - `WECHAT_APP_SECRET`：测试号 appsecret。
   - `WECHAT_OPEN_ID`：关注测试号后，用户列表里你自己的微信号标识。
   - `WECHAT_TEMPLATE_ID`：新增模板的模板 ID。
5. 先上传一份当日日报到 `digests/YYYY-MM-DD.json`，检查 Pages 发布成功。
6. 添加 Repository variable `WECHAT_ENABLED`，值为 `true`。手动运行工作流，勾选 `send_wechat`，验证手机收到通知。
7. 验证成功后，将仓库地址写入当前 Codex 定时任务并启用。保留唯一一个调度，避免重复发送。

模板内容（原样复制）：

```text
日期：{{date.DATA}}
今日简报：{{summary.DATA}}
{{remark.DATA}}
```

## 运行条件与失败处理

- 当前任务是桌面端本地定时任务，运行时需保持电脑开机、联网且 Codex 可运行；这不是仅凭 Plus 在 GitHub 云端独立生成摘要的方案。
- GitHub 发布和微信投递需要时间，9 点是任务启动时间，不保证9点整到账。
- 首次推送以手机实际收到为准。接口成功仅表示微信接受请求。
- 不自动重试微信发送；超时可能意味着已经发送，请先检查手机。工作流重新运行默认不会再次推送；手动勾选发送可以重发。
- 2026-09-16首次测试中，微信接口接受通知，用户已确认手机收到。后续如账号权限或网络设置变化，应根据工作流结果排查。
- 旧日期或超过6小时的日报不会推送。公开网页只包含新闻，四个微信配置值只放 Secrets。

## 日报格式

2026-09-17起使用七板块格式；2026-09-16及此前的四板块存档保持可读取。每日新建一次 `digests/YYYY-MM-DD.json`，不要修改既有日报触发重复推送。JSON 包含 `date`（纽约日期）、`generated_at`（带时区的 ISO 时间）、`sections`（七个固定板块（按上文顺序））。每个板块包含 `name`、`items`；条目包含 `summary`、`source`、`url`、`published_at`。空板块需要 `note`。链接必须是可信来源的 HTTPS 原文地址。

来源只有日期时，`published_at`保留`YYYY-MM-DD`，另加`published_timezone`（如`+08:00`）；此时只接受来源当地当天的新闻，不编造时分秒。
